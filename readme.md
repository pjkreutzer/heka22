# Course: heka22 - Ecological Economics

This course was given in VT26 at Department of Geography, Lund University at the Bachelor level.

Author: Jonas Kreutzer

## Repo Structure

- `presentations/` -- Standalone RevealJS slides (each `.qmd` renders independently)
- `lecture_notes/` -- Quarto book project (companion website), renders to `docs/`
- `_extensions/` -- Shared Quarto theme extension
- `lecture_notes/_extensions` -- Symlink to `../_extensions` so the book and presentations share one copy of the theme
